# Hệ thống đa ngôn ngữ

Douyin HD Pro v2.0.0 dùng hai lớp runtime và một lớp metadata:

1. `extension/i18n.js`: dictionary nền và API runtime.
2. `extension/i18n-v200-vi.js`, `i18n-v200-en.js`, `i18n-v200-extra.js`: chuỗi UX v2; Tiếng Việt và English đầy đủ, các locale còn lại có bản dịch các phần chính và fallback an toàn sang English khi thiếu chuỗi.
3. `extension/_locales/*/messages.json`: tên/mô tả Extension theo locale Chrome.

Ngôn ngữ mặc định là **Tiếng Việt**. Font giao diện ưu tiên `Segoe UI Variable Text`, `Segoe UI`, `system-ui`, `Noto Sans` để hiển thị dấu tiếng Việt rõ trên Windows mà không đóng gói font bên ngoài.

Các locale hiện hỗ trợ:

- `vi` — Tiếng Việt
- `en` — English
- `zh-CN` — 简体中文
- `zh-TW` — 繁體中文
- `ko` — 한국어
- `ja` — 日本語
- `th` — ไทย
- `id` — Bahasa Indonesia
- `es` — Español
- `fr` — Français

Ngôn ngữ được lưu trong `chrome.storage.sync`. Chuỗi mới phải có ít nhất bản Tiếng Việt + English; nên dịch trực tiếp cho 8 locale còn lại trước khi phát hành.

CI kiểm tra cú pháp runtime dictionary và đúng 10 thư mục `_locales`.
