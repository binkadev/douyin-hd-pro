# Hệ thống đa ngôn ngữ

Douyin HD Pro v1.1.0 có 4 lớp bản địa hóa:

1. `extension/i18n.js`: từ điển runtime nền và danh sách 10 ngôn ngữ.
2. `extension/i18n-v104.js`: lớp tương thích chuỗi từ v1.0.4.
3. `extension/i18n-v110.js`: chuỗi cho onboarding mới, thư mục tùy chỉnh và cơ chế phiên video của v1.1.0.
4. `extension/_locales/*/messages.json`: metadata của Chrome Extension như tên và mô tả theo locale trình duyệt.

Ngôn ngữ runtime mặc định là `vi`. Lựa chọn được lưu bằng `chrome.storage.sync`.

Các mã hỗ trợ: `vi`, `en`, `zh-CN`, `zh-TW`, `ko`, `ja`, `th`, `id`, `es`, `fr`.

Khi thêm ngôn ngữ mới cần cập nhật `LANGUAGES`, dictionary runtime, `_locales` và bài kiểm tra CI.
