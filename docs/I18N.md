# Hệ thống đa ngôn ngữ

Douyin HD Pro v1.0.3 có 2 lớp bản địa hóa:

1. `extension/i18n.js`: giao diện runtime, cho phép người dùng đổi ngôn ngữ ngay trong popup. Lựa chọn được lưu bằng `chrome.storage.sync`.
2. `extension/_locales/*/messages.json`: metadata của Chrome Extension như tên và mô tả theo locale trình duyệt.

Ngôn ngữ runtime mặc định là `vi`.

Các mã hỗ trợ: `vi`, `en`, `zh-CN`, `zh-TW`, `ko`, `ja`, `th`, `id`, `es`, `fr`.

Khi thêm ngôn ngữ mới cần cập nhật `LANGUAGES`, dictionary trong `i18n.js`, `_locales` và bài kiểm tra CI.
